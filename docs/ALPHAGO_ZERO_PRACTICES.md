# AlphaGo-Zero Practices Ported to PrimeArena

PrimeArena is not a literal AlphaGo clone. The prime task is a single-agent cost-minimization search problem, not a two-player zero-sum board game. This file tracks which AlphaGo-Zero-style practices are implemented, adapted, and still incomplete.

## Implemented in v0.3

- Single policy/value network: `PolicyValueNet(obs) -> logits, value`.
- Three backbone choices:
  - `residual_mlp` for backwards-compatible flat observations.
  - `candidate_transformer` for candidate-wise attention over the search window.
  - `candidate_conv` for cheaper candidate-local residual convolutions.
- MCTS uses policy priors, visit counts, mean action values, and PUCT-style selection.
- MCTS visit counts produce the policy target for training.
- Batched MCTS leaf inference via `run_mcts_batch`, so multiple independent search trees share GPU forward passes.
- Value targets are clipped to `[-1, 1]` to match the tanh value head.
- Root Dirichlet exploration noise is available and enabled by config.
- Replay buffer stores `(state, search_policy, value_target)` tuples.
- Replay shards can be generated by distributed self-play/search workers and then consumed by the learner.
- Loss is policy cross-entropy + value MSE + small entropy bonus + AdamW weight decay.
- Gradient clipping is enabled.
- CUDA AMP and TF32 are enabled for GPU runs where available.
- Cosine LR annealing is configurable.
- Best checkpoints are saved by evaluation success and by model-vs-baseline delta.
- Checkpoint league / arena evaluation compares checkpoints on identical seeds.
- Adversarial hard-case curriculum mines `n` values with large gaps / high wheel-baseline costs and mixes them into training.
- Interpretability probes and ablations test whether activations encode mod-6/mod-30/mod-210 structure.
- TensorBoard + JSONL + Streamlit dashboard logging are included.
- Baselines and success benchmark gates are included to prevent mistaking trivial sieve behavior for progress.

## Adapted rather than copied

- AlphaGo Zero uses residual CNNs over a Go board. PrimeArena v0.3 uses candidate-wise transformer/conv architectures over the prime-search window.
- AlphaGo Zero uses two-player self-play. PrimeArena uses self-generated search episodes plus an adversarial curriculum that selects difficult `n` values.
- AlphaGo Zero's value target is win/loss. PrimeArena's reward includes cost shaping, so the value target is clipped/normalized for stability.
- AlphaGo Zero's arena compares agents in a symmetric game. PrimeArena's arena compares checkpoints on identical seeded prime-search episodes using success, cost, and wrong-guess penalties.

## Still incomplete / future scale-up

- Multi-node learner gradient synchronization is not implemented. The current design is distributed self-play/search workers + one learner consuming shards.
- The adversary is a hard-case miner, not a separately trained neural adversary yet.
- League evaluation is greedy-policy by default to keep cost manageable; MCTS-based league evaluation can be added later.
- Mechanistic interpretability is first-pass: linear probes and causal input ablations, not full circuit discovery.
